# Changelog

## 1.1.0

- Renamed the project to **DCS F10 To Waypoint**.
- Replaced the unreliable existing-marker reader with a consistent client-only F10 point workflow.
- Added automatic point acquisition from DCS's native coordinate-window **COPY** action.
- Removed marker refresh controls, unavailable-marker messages, mission/scripting API access, and obsolete source modules.
- Simplified and improved the in-game interface.
- Retained all tested and experimental aircraft integrations from 1.0.1.
- Renamed scripts, logs, installer files, managed loader, and installation directories.
- Added automatic migration and backup of superseded installations.
